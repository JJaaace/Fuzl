## What changed

Connected ridge paths, river, a rising waterline and horizontal color gradients carry the transitions. A faded sea mask removes an edge found during the artwork review. The canyon's warm lighting is carried forward in the new illustrated style; the earlier generated raster remains in the repository.

The entire world is included at first render, with an exact repeated SVG group after it; no upcoming scene relies on an image download. The 120-second, linear right-to-left transform travels exactly one world length. Birds, fish and shark have small, slow secondary glides. Only scenery moves; cards remain outside the track. Desktop height is `clamp(143px, 15vw, 195px)`, previously `190px/20vw/260px`; phones use 126px, previously 170px. Track width follows the SVG's 60:1 proportions, so a phone sees a tighter crop rather than distorted ridges/animals. The redundant Sample data eyebrow is removed; the heading still identifies this as a sample gallery.

`JourneyLandscape.tsx` mounts trusted, repository-authored SVG once. `journeyMotion.ts` changes pause flags, never the artwork or its animation time: intersection and tab visibility pause it; **Pause scenery** / **Resume scenery** preserves the current phase. Reduced motion uses the static canyon and hides the unnecessary pause control. No per-frame React state, new dependency, font, remote image or AI artwork request is involved. `scripts/make-journey-art.mjs` is the editable original source for the generated `journeyArtwork.ts` constant.

**Ribbon diagnosis before timing changes.** Browser discovery returned no available browser, so the reported visual flash could not be reproduced or attributed conclusively in Safari. Before changing timing, two focused tests failed against the original code (captured in ignored `artifacts/design/ribbon-before-diagnostics.tap`):

- A valid 384px in-window move after a sharp turn hit the distance/velocity “teleport” rule, erased the cached S and returned a single point. That frame cannot draw a ribbon.
- The captured scroll handler cleared the path for every scroll, including control scrolling. After that, one ordinary move still had no drawable stroke.

Both pass after the fix. Distance alone no longer resets a live stroke; actual leave, blur, visibility, stage/size changes, touch/reduced motion and full expiry still clear as intended. Scroll retains the path and translates its coordinates by the canvas's changed viewport origin, shifting shared raw/cache endpoints only once. Composer crossing still smoothly lowers opacity without clearing history. The cached spline, interpolated trim point, stationary head, taper and gesture-sensitive interior strands remain. Lifetimes and minimum expiry spacing are multiplied by 0.8: a full-energy stopped tail takes 672ms instead of 840ms (25% faster catch-up). Active history is correspondingly shorter; no speed or turn reset is added. S/loop/corner and mid-retraction extension still retain their baked vertices and bends.
